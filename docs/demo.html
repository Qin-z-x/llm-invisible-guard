Invisible Unicode in a document that looks completely normal

This page is a real demonstration for invisi-guard v0.1.0. The memo below contains two hidden instruction payloads written with invisible Unicode characters (zero-width binary and Unicode Tags). The visible text is byte-for-byte the same as the clean memo. Toggle the panels to reveal what an LLM reading the raw text would see. Everything is decoded locally; the page makes no network requests.
